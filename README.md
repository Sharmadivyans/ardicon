## 🚀 Core Features (As Per Architecture Plan)

1. **Multi-Param Property Search & Filter Engine**:
   - Filter by Purpose (*Buy / Rent / Commercial / Plots*), Locality (*YEIDA, GNIDA, Noida, UPSIDC*), Property Type, and INR Price range (*₹25 Lakh to ₹20+ Crore*).
   - Instant Grid View / List View / Leaflet Interactive Map View toggle.
2. **Comprehensive Property Details Modal**:
   - High-resolution gallery & thumbnail viewer.
   - Financial EMI & Loan Calculator (interactive loan amount, interest rate, tenure, and monthly installment breakdown).
   - Social proof metrics (*"14 investors viewed today • 4 inquiries"*).
   - Proximity and driving time markers to **Noida International Airport (Jewar)**, Yamuna Expressway, Metro stations, and F1 Buddh International Circuit.
   - Instant WhatsApp inquiry button (`wa.me/919810273855`) and direct call action.
3. **Property Comparison Matrix**:
   - Side-by-side comparison of up to 3 properties (Authority approval, Area, Price per unit, Possession, Locality).
4. **Locality & Infrastructure Intelligence Guides**:
   - Dedicated guides for YEIDA Master Plan 2041, Greater Noida Commercial Belt, and UPSIDC Industrial Zones with YoY capital growth rates.
5. **Instant Valuation & Rate Index Lead Magnet**:
   - Calculates real-time market value estimation based on verified circle rates and registers prospective buyer/seller leads.
6. **Multi-Step "List Your Property" Wizard**:
   - 5-step intuitive submission form with draft review and instant publishing to live inventory.
7. **Mini-CRM & Admin Command Center**:
   - Real-time Lead Tracking Table with pipeline statuses (`New`, `Contacted`, `Site Visit Scheduled`, `Converted`, `Lost`).
   - Property Inventory Moderation Queue (Approve, Unpublish, Feature).
   - Performance Analytics (Total Leads, Active Site Visits, Conversion Rate %).
   - One-click CSV Lead Export.
